Bridge Pattern

FileManager → Storage

FileManager handles the rules. Storage handles saving and loading. The storage choice can change without changing FileManager.

Implementations: FolderStorage and SnapshotStorage.

Protection Proxy

FileAccessProxy → RealFileService

The proxy checks the file’s owner and sharing information before allowing protected operations. The real service performs allowed operations.

Folder rule

A folder that still contains files cannot be deleted. Files must be moved or deleted first.

Users

Tima, Salta, and Guest are predefined. The person who creates a file owns it. A viewer can read only files shared with them.
